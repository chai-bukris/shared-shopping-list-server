# Shared Shopping List Android app

This folder contains the Android Studio project for the Java/XML client.

Open this folder in Android Studio to edit and build the app. A debug APK is generated at:

`app/build/outputs/apk/debug/app-debug.apk`

The project requires Android 7.0 (API 24) or newer. It connects to the shared shopping-list service configured in `app/src/main/java/com/example/sharedshoppinglist/ApiClient.java`.

The Render service configuration remains at the repository root and continues to build `server.py`; this Android project is kept in a separate subfolder.
